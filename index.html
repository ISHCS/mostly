Roles & Role-Based Access Control (RBAC) Architecture

The Bishoftu Management System uses a robust multi-tier permission model tailored for site operations.

Site Manager (Admin)

Full privileges. Can manage employee credentials, view/edit all operational modules, run SQL console backups, and override entries.

Fleet Supervisor

Manages machinery performance logs, fuel dispensing records, and dump truck haulage cycle counts.

Finance & Petty Cash

Manages petty cash vouchers, operational expenses, and site income reports.

Machine Operator

Logs daily machine hours, fuel consumption, and basic production output.
