🛡️ Role-Based Access Control (RBAC) Matrix

The Bishoftu Management Portal enforces strict role permissions across site operations to ensure data integrity and security.

Site Manager
Full Access (Admin)

Can view, add, edit, and delete all operational logs, employee credentials, database backups, and run SQL queries.

Fleet Supervisor
Fleet & Machinery

Manages fuel issues, machine performance logs, dump truck haulage counts, and equipment maintenance schedules.

Finance Manager
Financial Control

Manages petty cash vouchers, site expenses, haulage revenue, and purchase request approvals.

Machine Operator
Operator Entry

Can submit daily fuel consumption reports, machine hours, and create purchase requisitions.
