Roles & Role-Based Access Control (RBAC) Matrix

The system enforces strict permission boundaries based on user profiles to maintain operational data integrity across the Bishoftu quarry and site facilities.

👑 Site Manager

Full administrative access across all tabs, user credentials management, backup/restore, and database SQL console.

🚜 Fleet Supervisor

Manages machine logs, fuel reports, dump truck haulage, and reviews purchase requests.

💵 Finance & Petty Cash

Manages petty cash vouchers, other site expenses, site income records, and financial approvals.

👷 Machine Operator

Submits daily fuel issues, machine operating hours, haulage counts, and purchase requisitions.
