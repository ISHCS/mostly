Role-Based Access Control (RBAC) Architecture

The Bishoftu Management System implements strict hierarchical security roles. Administrators and Site Managers hold full editing and management authority across all modules.

👑 Site Manager / Admin

Full editing and record management across all tabs, employee credential generation, database backup/restore, and SQL console access.

🚜 Fleet Supervisor

Manages heavy machinery logs, fuel issues, dump truck cycle counts, and excavation production reporting.

💵 Finance & Petty Cash Manager

Manages petty cash vouchers, operational expenses, site income records, and financial balance audits.

⚙️ Machine Operator

Logs daily operational hours, fuel consumption, and submits purchase requisitions for spare parts.

Local SQL / Query Console (Admin Only)

Execute structured queries against tables: users, fuel, machine, dumptruck, excavation, pettycash, expenses, income, purchaserequests.
