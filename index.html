Role-Based Access Control (RBAC) Matrix

The Bishoftu system enforces strict permissions based on your assigned user role:

👑 Site Manager (Admin)

Full administrative access across all tabs, employee credential management, backup/restore, and database SQL console.

🚛 Fleet Supervisor

Can log and edit Fuel Reports, Machine Performance logs, Dump Truck haulage, and Excavation progress.

💵 Finance Manager

Full control over Petty Cash vouchers, Other Expenses, Site Income, and Purchase Requests.

🚜 Machine Operator

Can view operational dashboards and submit routine daily equipment logs and purchase requisitions.
